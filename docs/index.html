Custom CLI Formulae for Homebrew

Maintained by Ata Can Yaymacı. Install standalone tools and art generators with standard Homebrew commands.

Terminal: Tap the repository
$ brew tap AtaCanYmc/tap
$ brew install lumina

Available Formulae

Browse tools packaged in this repository.

forex-pytory

v0.1.2 Apache-2.0
Source

Economic calendar scraper CLI and MCP server across financial markets. Extracts and normalizes macroeconomic calendar events from ForexFactory, CryptoCraft, EnergyExch, and MetalsMine.

Single-command install:
brew install AtaCanYmc/tap/forex-pytory
Dependencies:
  • python@3.12
  • cryptography
  • numpy
CLI Examples:
# Render calendar table in terminal
forex-scraper --source forex --format table
# Start FastMCP server
forex-mcp

lumina

v1.0.0 MIT
Source

Lithophane and Spiral Betty 3D Art Generator CLI. Converts 2D raster images into 3D-printable lithophane STL meshes and single-spiral drawings.

Single-command install:
brew install AtaCanYmc/tap/lumina
Dependencies:
  • python@3.12
  • numpy
  • opencv
CLI Examples:
# Generate a circular lithophane STL
lumina flat photo.jpg --shape circle --width 120
# Generate a Spiral Betty PNG pattern
lumina spiral portrait.jpg --radius 100 --lines 40
View Formula/lumina.rb on GitHub →

Brewfile Integration

Include formulae in reproducible development environments using brew bundle.

Brewfile 
tap "AtaCanYmc/tap"
brew "forex-pytory"
brew "lumina"
brew "resmi-gazete-cli"
brew "robo-market-search"
brew "rxresume"
brew "yargitay-karar-scraper"
Install all items declared in your Brewfile:
brew bundle

Maintenance and Verification

Homebrew verification commands to inspect and test formulae locally.

Audit syntax and style constraints

brew audit --strict AtaCanYmc/tap/lumina

Execute formula integration test block

brew test AtaCanYmc/tap/lumina

Test build from source

brew install --build-from-source AtaCanYmc/tap/lumina
